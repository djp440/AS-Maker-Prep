# Avellaneda做市策略开发文档

## 项目概述
基于Avellaneda-Stoikov模型的自动合约做市程序，使用Node.js + CCXT在Bitget交易所执行多交易对做市策略。

## 技术栈
- **运行环境**: Node.js 18+
- **交易框架**: CCXT
- **配置管理**: dotenv
- **日志系统**: Winston
- **时间处理**: Day.js

## Bitget交易所接口

### 连接方式
- **数据获取**: WebSocket (账户、订单、行情)
- **订单操作**: REST API (下单、撤单)

### WebSocket限制
- **连接**: 5分钟内最多300次连接，单IP最多100并发
- **订阅**: 每小时最多240次订阅，单连接建议≤50频道
- **心跳**: 30秒发送ping，2分钟无响应断开
- **重连**: 24小时强制断开，需自动重连
- **速率**: 每秒最多10消息

### 连接稳定性机制
- **重连策略**: 指数退避(1s-60s)，清理订阅状态，限制重连次数
- **状态恢复**: 重连后同步账户状态，对比订单变化，重新订阅频道
- **连接监控**: 监控连接状态、数据流、延迟指标

### API速率控制
- **频率控制**: 令牌桶算法，优先级队列(紧急订单>查询>历史)
- **并发控制**: 限制并发数，关键操作串行化
- **错误处理**: 识别限制错误码，智能重试，IP封禁保护

### 模拟盘配置
要启用模拟盘功能，请在 `.env` 文件中进行相应配置。您需要使用模拟盘专用的API Key，并根据CCXT的规范在请求中添加额外参数。

**模拟盘REST API**
- **启用方式**: 在CCXT实例化时，通过 `options` 对象设置 `papertrading: true` 或类似的参数，具体取决于CCXT对Bitget模拟盘的支持方式。通常，这会通过在请求头中添加 `paptrading: 1` 来实现。
- **API Key**: 请使用您在Bitget模拟盘申请的API Key、Secret和Passphrase。

**模拟盘WebSocket**
- **连接地址**:
  - **公共频道**: `wss://wspap.bitget.com/v2/ws/public`
  - **私有频道**: `wss://wspap.bitget.com/v2/ws/private`
- **认证**: 使用模拟盘的API Key进行认证。

在代码实现中，需要根据配置动态切换实盘与模拟盘的API端点和WebSocket地址。

### WebSocket认证
**认证字段**: api_key, passphrase, timestamp, sign

**签名算法(HMAC-SHA256)**:
```
Message = timestamp + "GET" + "/user/verify"
Signature = hmac_sha256(API_SECRET, Message)
sign = base64.encode(Signature)
```

**BASE_SPREAD百分比计算**:
```javascript
// 将百分比转换为实际价差
const actualSpread = midPrice * BASE_SPREAD;
const bidPrice = midPrice - actualSpread / 2;
const askPrice = midPrice + actualSpread / 2;

// 示例：BTC价格50000，BASE_SPREAD=0.001(0.1%)
const actualSpread = 50000 * 0.001; // 50 USDT
const bidPrice = 50000 - 25; // 49975
const askPrice = 50000 + 25; // 50025
```

### 参数说明
- **SYMBOL**: 交易对(CCXT格式)
- **RISK_AVERSION**(γ): 风险厌恶系数，影响库存对报价的调整幅度
- **BASE_SPREAD**: 基础价差百分比，零库存时的最小买卖价差(如0.001表示0.1%)
- **ORDER_AMOUNT**: 单次下单占总权益百分比(如0.01表示1%)
- **MAX_INVENTORY**: 最大库存占总资产比例(如0.2表示20%)
- **VOLATILITY_LOOKBACK**: 波动率计算回看周期(K线数)
- **KLINE_INTERVAL**: K线周期
- **LEVERAGE**: 杠杆倍数
- **TRADE_SIDE**: 交易方向(long/short/both)

## 核心算法：Avellaneda-Stoikov

### 预留价格(Reservation Price)
**公式**: `r = s - q * γ * σ²`
- `s`: 市场中间价
- `q`: 标准化库存量(多头为正，空头为负)
- `γ`: 风险厌恶系数
- `σ`: 市场波动率

### 标准化库存量计算
**公式**: `q = (持仓价值 / 总资产) / MAX_INVENTORY`

**计算步骤**:
1. 持仓价值 = |持仓数量| × 当前市价
2. 库存比例 = 持仓价值 / 总资产
3. 标准化库存量 = 库存比例 / MAX_INVENTORY
4. 符号: 多头为正，空头为负

**示例**: 
- 总资产100,000 USDT，BTC持仓0.5个，价格50,000
- 持仓价值 = 0.5 × 50,000 = 25,000 USDT
- 库存比例 = 25,000 / 100,000 = 0.25
- 若MAX_INVENTORY=0.2，则q = +0.25/0.2 = +1.25

**核心逻辑**: q>0时降低报价吸引卖单，q<0时提高报价吸引买单

### 最优价差
**公式**: `Spread = BaseSpread + VolatilitySpread * σ`

### 最终报价
- **卖价**: `Ask = r + Spread/2 = (s - q*γ*σ²) + Spread/2`
- **买价**: `Bid = r - Spread/2 = (s - q*γ*σ²) - Spread/2`
对于交易方向为long的场景，应该在买价处开多仓，在卖价处平多仓
对于交易方向为short的场景，应该在卖价处开空仓，在买价处平空仓
对于交易方向为both场景，应该在买价处开多仓、平空仓，在卖价处开空仓、平多仓

### 风险控制机制

**异常检测**:
- 波动率上限阈值(如3倍日均)，超过暂停报价
- 价差保护，最大不超过市场价差2倍
- 中间价验证，异常时使用成交价/VWAP

**库存管理**:
- 通过预留价格公式 `r = s - q * γ * σ²` 自动调节报价
- 当库存过多(q>0)时自动降低报价吸引卖单
- 当库存不足(q<0)时自动提高报价吸引买单
- 算法本身具备自平衡机制，无需额外人工干预

## 合约交易执行逻辑

### 交易信号
- **开多**: 无仓/空仓时买入信号
- **平多**: 多仓时卖出信号  
- **开空**: 无仓/多仓时卖出信号
- **平空**: 空仓时买入信号

### 交易所精度处理

**价格精度调整**:
```javascript
// 根据交易所规则调整价格精度
function adjustPrice(price, tickSize) {
    return Math.round(price / tickSize) * tickSize;
}
```

**数量精度调整**:
```javascript
// 根据交易所规则调整数量精度
function adjustQuantity(quantity, stepSize, minQty) {
    const adjusted = Math.floor(quantity / stepSize) * stepSize;
    return Math.max(adjusted, minQty);
}
```

**关键精度参数**:
- `tickSize`: 价格最小变动单位(如0.1, 0.01)
- `stepSize`: 数量最小变动单位(如0.001)
- `minQty`: 最小下单数量
- `minNotional`: 最小下单金额(价格×数量)

**实际报价示例**:
```javascript
// 理论计算结果
const theoreticalBid = 49999.97998;
const theoreticalAsk = 49999.98002;

// 精度调整后
const actualBid = adjustPrice(theoreticalBid, 0.1); // 49999.9
const actualAsk = adjustPrice(theoreticalAsk, 0.1); // 50000.0
```

## 参数分类

### 私密参数(.env)
- `API_KEY`: Bitget API Key (实盘)
- `API_SECRET`: Bitget API Secret (实盘)
- `API_PASSWORD`: Bitget API Passphrase (实盘)
- `PAPER_API_KEY`: Bitget API Key (模拟盘)
- `PAPER_API_SECRET`: Bitget API Secret (模拟盘)
- `PAPER_API_PASSWORD`: Bitget API Passphrase (模拟盘)
- `PAPER_TRADING`: 是否启用模拟盘 (true/false)

### 策略参数(config.json)
配置文件中的所有交易对参数

### 动态参数(程序计算)
- `market_mid_price`(s): 市场中间价
- `normalized_inventory`(q): 标准化库存量
- `volatility`(σ): 市场波动率
- `reservation_price`(r): 预留价格
- `ask_price/bid_price`: 最终报价
- `risk_level`: 风险等级

## 风险管理与错误处理

### 库存风险控制
- 下单前检查: 持仓+活动订单+新订单 ≤ MAX_INVENTORY
- 实时监控库存变化和"在途"订单影响
- 超过120%阈值时强制减仓

### 订单管理
- 订单超时机制(5分钟自动取消)
- 价格偏离检查，超阈值重新报价
- 定期同步订单状态，防止"僵尸"订单

### API异常处理
- 网络错误: 指数退避重试
- 交易所错误: 按错误码分类处理
- 熔断机制: 连续错误时暂停交易
