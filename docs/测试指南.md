# AS-Maker-Prep 测试指南

## 测试概述

本测试套件专门验证前两个阶段的核心功能：
- **第一阶段**：基础服务与配置 (Foundation)
- **第二阶段**：交易所接口与数据服务 (Connectivity & Data)

**测试目标**：确保系统能够成功对接Bitget交易所模拟盘，REST API和WebSocket都能正常获取数据。

## 测试前准备

### 1. 环境配置

```bash
# 1. 复制环境配置模板
cp .env.example .env

# 2. 编辑 .env 文件，填入您的Bitget API凭证
# 注意：建议使用模拟盘进行测试
```

### 2. API凭证配置

在 `.env` 文件中配置以下信息：

```env
# 模拟盘API凭证（推荐用于测试）
PAPER_API_KEY=your_paper_api_key
PAPER_API_SECRET=your_paper_api_secret
PAPER_API_PASSPHRASE=your_paper_passphrase

# 启用模拟盘模式
PAPER_TRADING=true
```

### 3. 依赖安装

```bash
# 确保所有依赖已安装
cnpm install
```

## 测试结果解读

### 成功标志

- ✅ **通过**：功能正常工作
- 🎉 **全部通过**：所有测试项目成功

### 失败处理

- ❌ **失败**：功能存在问题
- ⚠️ **部分失败**：部分功能有问题

### 常见问题排查

#### 1. 配置加载失败

**可能原因**：
- `.env` 文件不存在或格式错误
- `config.json` 文件格式错误
- API凭证配置错误

**解决方案**：
- 检查 `.env` 文件是否存在且格式正确
- 验证API凭证是否有效
- 确认 `config.json` 中的交易对格式正确

#### 2. 交易所连接失败

**可能原因**：
- 网络连接问题
- API凭证无效
- API权限不足
- 服务器维护

**解决方案**：
- 检查网络连接
- 验证API凭证和权限
- 确认Bitget服务状态

#### 3. WebSocket连接超时

**可能原因**：
- 网络不稳定
- 防火墙阻止WebSocket连接
- 服务器负载过高

**解决方案**：
- 检查网络稳定性
- 配置防火墙允许WebSocket连接
- 稍后重试

#### 4. 数据接收异常

**可能原因**：
- 订阅参数错误
- 交易对不存在或已下线
- 市场数据延迟

**解决方案**：
- 检查交易对符号格式
- 确认交易对在交易所正常交易
- 等待更长时间接收数据

## 测试最佳实践

### 1. 测试顺序建议

1. **首次测试**：运行 `npm run test:core` 进行快速验证
2. **详细测试**：运行 `npm run test:rest` 验证API功能
3. **实时数据测试**：运行 `npm run test:websocket:data` 验证数据流
4. **完整验证**：运行 `npm run test:all` 进行全面测试

### 2. 测试环境建议

- **优先使用模拟盘**：避免影响真实资金
- **稳定网络环境**：确保测试结果准确
- **充足测试时间**：WebSocket测试需要30秒左右

### 3. 测试数据记录

建议记录以下信息：
- 测试时间和环境
- 测试结果和错误信息
- 网络状况和延迟
- API响应时间
