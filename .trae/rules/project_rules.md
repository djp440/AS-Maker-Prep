# 项目文件
@docs/开发文档.md 项目的总体开发文档
@docs/modules/ 该文件夹包含项目各个模块的开发文档
@docs/TODO.md 项目的TODO列表

# 编码流程
1. 浏览项目，了解项目内容和结构
2. 查看TODO列表，对项目进度进行了解
3. 根据用户的要求、总体开发文档进行编码，还需要参阅正在构建的模块的开发文档
4. 编码完成后，编写测试脚本对编写的内容进行测试，测试脚本统一放置在test文件夹中（如果没有这个文件夹就创建一个）
5. 测试无问题，且用户也认为无问题后，在TODO列表中标记已完成。
6. 测试完成清理测试文件

# 注意事项
1. 在安装依赖时使用cnpm替代npm
2. 尽量不要使用curl
3. 编码风格应该简洁、易读、易维护，每个函数都需要有符合JSDoc格式的注释
4. 在终端中使用PowerShell语法
5. 不要使用沙盒环境，bitget交易所没有沙盒环境
6. 始终使用ccxt框架与交易所进行连接，不要自己编写api请求
7. 首选中文编写注释和信息文本
8. 开发过程中随时注意检查语法错误和调用、导入错误
